# HOW TO CONTRIBUTE

1) Inside the *contributors* directory, create your personal directory where all your work will be added.
2) Create a link to your work inside the root *index.html* file.
3) Style your link as you see fit using ID selector inside *links.css*
4) Your link must be visible and clickable.
5) Minimum of 0.5rem of margin around your link (max. of 1.5rem).
6) Max width = 120px.
7) Max height: 100px.
8) Your link should not overlap with other's link.
9) When adding your link, make sure to consider mobile screens too.
10) Let's have fun.

NOTE: DO NOT STYLE ANY OTHER THING IN THE BASE OTHER THAN YOUR LINK
